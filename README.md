Bold each of the Glossary words as you use them.  Bold ONLY the glossary word.

    Branch -Is copy of the code that is not in production. Used for developers to create new code that does not interfere with the production code found in the main branch. 
    Clone -A copy of the code brought down to the develpoment environment. 
    Commit -Individual change to a file; once saved, GitHub will make a unique ID allowing people to keep records of changes made. 
    Fetch -This adds changes from the remote repository to ones own branch. 
    GIT -Open source program that tracks changes in text files and is the core part of GitHub. 
    GitHub -Gives services to entire organizations and uses its own identity when performing.  
    Merge -Turns changes from one branch and applies them to another. 
    Merge Conflict -Difference happened due to branches put together. This happens when there are changes to different lines in the same files. 
    Push -Means to send committed changes to a remote repository. 
    Pull -Means fetching changes and combining them. 
    Remote -A repository/Branch hosted on a server.  
    Repository -The most basic element here. A repository has all project files and has their history.
